Setup guide

Setting Up NinjaTrader 8

Nine settings you make once, so the platform stops being a variable on a trading day.

All tools

This page covers NinjaTrader 8 (NT8) for trading MNQ. Everything here is a mechanic you set once and write down. Menu names and defaults change between releases, so each section links the vendor page that owns the detail. Where the research has a gap, the page says so and gives no steps for it.

1. Install

  1. Install Microsoft .NET Framework 4.8 first.
  2. Log in to your NinjaTrader account, download the installer from the account portal and run it.
  3. Allow NinjaTrader through the firewall and any anti-spyware tool. If you do not, login validation fails.
  4. Follow the connection guide for your broker or data feed (section 3).

NT8 runs on Windows. On a Mac it needs a virtual machine. Recommended hardware is a 2 GHz quad-core CPU, 8 GB of RAM and an SSD; RAM is the main bottleneck. Use a wired internet connection, because wireless and satellite links drop packets or add latency.

  • Updates install over the existing version with no uninstall. Save the installer locally and back up first (section 9).
  • Downgrading needs a full uninstall and reinstall plus a restore of the database, add-ons, templates and workspaces, and it risks errors such as login failures. Keep local copies of installers and do not downgrade.
  • Cloud sync. Exclude the Documents\NinjaTrader 8 folder from cloud-sync and backup tools. File-access conflicts follow when you do not.
  • Windows 11 Smart App Control can block NT8 from loading freshly compiled unsigned assemblies, so an indicator silently fails to load.
  • Safe Mode. Hold CONTROL while NT8 launches, until the Control Center appears. Add-ons start disabled. Use it first when an add-on destabilises the platform.
  • After every upgrade, re-check working orders and re-test your settings. Past releases fixed bugs in ATM, OCO, Playback, Strategy Analyzer and Volume Profile behaviour.

2. License

  • The free plan allows indefinite charting, footprint and volume analysis, backtesting and simulated trading.
  • Real-time data, Order Flow+ and Market Replay unlock once the NinjaTrader brokerage account is funded. A live data trial comes with account opening.
  • Order Flow+ (volumetric bars, cumulative delta, delta bars, depth map, order-flow VWAP, trade detector, volume profile) is a paid add-on on top of the plan. The volumetric footprint in Module 07 needs it.
  • From release 8.1.1.0, license keys were replaced by a username login tied to your plan. An existing license is imported under Settings > Plans > Import a License, automatically on upgrade.
  • The NinjaTrader login protects only the account, entitlements and server-side ATM templates. Local workspaces, NinjaScript and connections are open to anyone who logs into the machine. On a shared machine use “Ask password on connect”.

Commission template: set it before the first trade

Trades synced without a commission template record zero commission, and a re-import never corrects it. Templates are assigned per account. Playback101 inherits Sim101’s settings. Cite the plan and fee pages for current amounts; this page prints none.

Vendor page: NinjaTrader pricing.

3. Connections

  1. Open Control Center > Connections and add your broker or data feed. Names are alphanumeric.
  2. Connect manually first and confirm the status indicator. Wrong credentials with “Connect on start up” ticked can block startup.
  3. Only then turn on “Connect on start up”.

Three connections ship permanently: free Kinetick End-of-Day, Playback and the Simulated Data Feed (synthetic data, no history).

  • NinjaTrader is not a data provider. Real-time and historical data, tick history and bid/ask history all depend on the connected provider. Check what your provider supplies before you rely on backfill.
  • With several connections, NT8 takes data from the first provider that supports the instrument class, while orders route to the selected account. A missing contract entitlement silently leaves that contract without data.
  • Delta needs bid/ask-stamped ticks from the provider. Without them NT8 falls back to up-tick and down-tick classification.
  • Price and order feeds are reported separately. Quotes can freeze while orders stay live, or the reverse. Watch both indicators.
  • After a disconnect, check every working order and the real position at your broker before you resume. Simulated and market-if-touched orders can come back as Unknown.
  • Level 1 data is enough for footprint, order flow and volume profile. The depth tools need a Level 2 subscription.
  • Funded-account route. A funded NinjaTrader brokerage account is the documented route to Level 1 CME data, and it carries an inactivity fee if the account sits idle. Check the fee page.
  • NinjaTrader Continuum: log in with the profile username from Settings > Profile, not the login email, and tick the required checkbox. Otherwise the feed fails silently.
  • Rithmic: the API can show a phantom position the broker has already closed. Check the true position at the broker before you use Flatten All.

Gap: connection steps per broker (NinjaTrader Brokerage, Rithmic, Tradovate) are not confirmed here. Use the vendor connection guide for yours.

4. Trading Hours templates

A Trading Hours template sets the session times and filters data everywhere it is applied. The levels you mark in Modules 04 to 06 are only as good as the session the chart is built on.

  • MNQ and MES ship on the CME US Index Futures ETH template. A matching CME US Index Futures RTH template ships with NT8.
  • The full-session ETH day opens the prior afternoon: a CME ETH session opening 5:00 PM Central belongs to the next trading day.
  • Use the same template on the chart Data Series and in Strategy Analyzer. Chart Template settings silently override manual Data Series values.
  • Each template carries its own time zone. The General time-zone setting controls display, and the auto-flatten time also follows it. Set it on purpose.
  • “Break at EOD” (off by default) cuts bars at the session end. It starts fresh volume and tick bars and can truncate range bars.
  • Prior-day and current-day levels come from the chart’s own session template. Overnight high, low and POC with custom session boundaries need custom code.
  • Holiday definitions update from the data server. CME finalises holiday schedules about two weeks out; check then and set a reminder for the day before.
  • A release can reset saved Trading Hours assignments (8.0.3.0 did), and the Database window can reset trading hours, commission and risk templates to the current server definitions. Back up first and re-check after upgrades.
Your two templates

The course draws its day boundary at 16:00 ET (D50). Build one RTH template and one full-session template, both ending 16:00 ET, and use them on every chart. Name them so you can tell them apart at a glance.

Gap: the exact session tables of the shipped templates and the step-by-step build of a template ending 16:00 ET are not confirmed here, so no row-by-row steps are given. Read the vendor page on Trading Hours templates and confirm in Playback that the prior-day high and low match your template.

5. Chart and footprint defaults

Set these once per market, save them as a chart template, and do not change them during the session. Module 07 gives the rule: footprint settings are written down, saved as one chart template, and changed only at a scheduled review, as a dated line.

Instrument check before the first trade

Open the Instrument Editor and confirm MNQ and MES show a tick size of 0.25 and match the CME contract page. Typing a symbol can fetch the wrong instrument: add it, press Escape and browse to the correct contract month. A local edit to an instrument stops its auto-updates, and the Update Instruments utility resets customisations.

Footprint

  • Order flow reads on time, tick, volume and Heikin-Ashi bars. It does not read on Renko.
  • NT8 ships volumetric bars with an imbalance ratio of 1.5, a minimum delta of 10 and diagonal comparison. Module 07 starts you at ratio 5 and minimum delta 15 as a working default and explains how to replace it with your own.
  • Aggregate ticks per row so the cells are readable and the CPU load stays down. Set row size by hand; the defaults are coarse.
  • Set the number, delta-summary and imbalance font sizes separately.

Tick Replay

Historical footprint data needs Tick Replay switched on globally (Tools > Options > Market Data) and then on each chart’s Data Series. Re-check the global setting, because it sometimes fails to propagate. Keep the history short; loads are slow and recalculation takes time and memory. Live charts do not need Tick Replay.

Keep the chart clean

Keep only elements that serve context, decision areas, execution timing, risk or exit targets. Forgotten lines, indicators and anchored VWAPs keep calculating and obscure the read. Switching on every order-flow tool at once adds noise.

Templates and workspaces

  • A Chart Template stores properties, panels and indicators, not drawings. Save one with all your settings and keep a local copy to restore after a crash.
  • An indicator or property template named “Default” loads automatically.
  • Plot only the traded instrument. If you add a correlated chart, treat it as context.

Rollover

Running strategies never roll automatically. After a roll, stale references (old-month level indicators, queued orders on the wrong contract) cause silent errors. Check each chart’s contract month.

Clock

Executions plot by timestamp, so a lagging PC clock can make valid fills look impossible. Keep the clock synced.

6. ATM template

An ATM strategy puts the stop and target on the order at the moment of entry, so the exit is set before the trade is live. Module 14 teaches the construction. This section is the platform mechanics.

  1. Create a basic ATM strategy with one stop loss and one profit target, in ticks.
  2. Save it as a named template. It is usable from every order-entry window except the Order Ticket.
  3. Stop and target are linked OCO: one fill cancels the other.
  4. Verify the stop value on every order. Do not trust a saved template. Past builds produced stops of zero.
  • Stop-market is the preferred stop type. A stop-limit caps the fill price but may not fill at all if price runs through.
  • Local versus server-side. A local ATM manages stops and targets only while NT8 is connected. From 8.1.1.0 an opt-in server-side ATM keeps them working through a disconnect. Reversing with a server-side ATM leaves a naked position, so close and re-enter instead.
  • The ATM dropdown: None (no bracket), Custom, a named template (a new bracket per order), or an active strategy, which attaches new fills to the existing bracket. Know which is selected before you click.
  • Closing: middle-click CLOSE closes only the selected ATM. Left-click flattens the instrument on the account. The wrong click closes the raw position and cancels all orders.
  • Rejected orders: a rejected entry sends no stops or targets, and a rejected stop or target cancels all of that ATM’s stops and targets. Look at the orders tab after every entry.
  • Time in force (Day or GTC) is enforced by the broker. Set Day, or cancel GTC leftovers at the end of the day.
  • Safeguards: “Confirm order placement” (Tools > Options > Trading) requires a confirmation per order. Keyboard focus left on the last order button lets Enter or Space resubmit it.
  • Hot keys (Control Center > Tools > Hot Keys, enabled under Tools > Options > Trading) fire only in the active order-entry window.
Leave these off

The course runs with automation off and the breakeven key unbound (D11). The one planned scale is half at 2R with the runner to the structural level; any other breakeven or trail is Too Early. So leave Auto Breakeven, Auto Trail, Auto Chase, Target Chase, Auto Reverse and the BE button unused, and unbind the breakeven hot key.

7. Daily loss limit

NinjaTrader 8 has no daily loss limit. The kill switch for a live account is set at the broker, not in the platform. Set it before the session, at 2R, and never raise it during the session (D29).

The Risk window in NT8 holds Risk Templates (margin, maximum order size, maximum position size per instrument). They apply to simulation accounts only. The platform’s Accounts grid shows daily and weekly loss limits only when the provider sends them.

NinjaTrader Brokerage live account

  1. Open the NinjaTrader Dashboard > User Profile > Settings > Accounts > Risk Settings (the Web App shield icon reaches the same place).
  2. Set the Daily Loss Limit to your 2R amount for the account.
  3. Turn on “Prevent Changes When Trading is Locked by Risk Settings”. With it on, you cannot raise or remove the limit after it fires, and only the broker’s Trade Desk can unlock the account that day.

The limit is enforced at the account level on every platform connected to that account. At the limit, positions close, orders cancel and the account goes liquidation-only. It is a liquidation trigger, not a guaranteed cap, because slippage still applies. NinjaTrader counts realized P&L, fees included. Read its page for the reset time.

Auto Close Position

Auto Close Position flattens at a time you set per instrument, globally or per order-entry window, using the General time zone. Set it to 16:00 ET to match the course day boundary (D50).

8. Market Replay

  • The Playback connection plays Market Replay files or historical tick data. Modes: current day only, from selected (default, the fastest) and from start. Alert conditions are checked about every 200 ms, so high speeds can skip alerts.
  • Market Replay data for popular futures can be downloaded from NinjaTrader’s servers through the Historical Data window.
  • Playback simulates bid and ask from stamped ticks, or approximates them. It models no latency, so its fills can be optimistic.
  • Use a dedicated Playback workspace so replay never touches your live drawings.
  • Sim101 and Playback101 accumulate commissions and do not support end-of-session time-in-force expiry.
  • Simulate only while live market-hours data streams. Off-hours bid/ask is erratic and fills land far from the last trade.
  • “Fill Limit Orders on Touch” fills a touched limit at the bar open, which loosens fill assumptions. When you practise limits, rest them a tick away so price must trade through.
  • Playback running at high speed shows mechanics. It is replay, not a statistical backtest.

Use replay for what it does well: after the close, replay the day tick by tick against your plan, and practise fill placement inside the level. One replay illustrates a drifted entry (n=1, from a single replay, so it measures nothing); replay trades are never part of your record.

Check that Sim101 and Playback101 trades are tagged as sim in your journal so they never enter a live figure.

Gap: how many days of MNQ replay data NinjaTrader’s servers supply is not confirmed here. Check the Historical Data window.

9. Backup

  1. Disconnect every connection.
  2. Control Center > Tools > Export > Backup File.
  3. Tick the items, choose the location and press Backup. The default folder is Documents\NinjaTrader 8 Backup, with the date as the filename.

A backup can hold configuration, the trade database, logs, NinjaScript, templates (chart, strategy, Market Analyzer, ATM, SuperDOM) and workspaces. Historical chart and Market Replay data can usually be downloaded again, so leaving them out keeps backups small, provided your provider still carries that period.

  • Restore through Control Center > Tools > Import > Backup File. A backup from another release may fail to import.
  • Back up before every upgrade.
  • Workspaces export and import from the Workspaces menu. NT8 keeps 10 recovery versions of each workspace by default, but deleting a workspace deletes them too.
  • NT8 offers no supported way to read past executions from its local database. Capture fills as they happen. The Executions tab exports the day’s fills to CSV or Excel.

Gap: the current Backup File dialog items and restore limits for the latest release are not confirmed here.

Before you go live

  • Instrument tick size 0.25 and contract month confirmed.
  • Commission template assigned to the account.
  • Price and order feeds both connected.
  • Trading Hours template and General time zone set on purpose.
  • Chart template saved; settings fixed for the session.
  • ATM template selected, stop value checked on the order.
  • Broker-side daily loss limit set at 2R, with changes locked.
  • Chart account and trading account match.
  • Backup taken.
Apply this now

Write the nine items above as a one-page checklist and tick it before your next session.
